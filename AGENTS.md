# borispacex web

## Project objective

Build the official borispacex commercial website.

The website is inspired by the quality, interaction and structure of
https://9lives.one/, but it must not copy its design, text, assets or source code.

## Repository

Repository name: web

## Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- Motion
- i18next
- react-i18next
- Lucide React

## Required features

- Spanish and English
- Dark, light and system themes
- Fully responsive
- Mobile-first
- Accessible navigation
- Optimized images
- Semantic HTML
- SEO-friendly metadata
- Good Lighthouse performance
- GitHub Actions validation

## Design direction

- Premium
- Modern
- Technological
- Minimal
- Subtle spatial identity
- Avoid excessive stars, planets or decorative effects
- Use the BX symbol and blue moon subtly
- Support both light and dark themes

## Engineering rules

- Use TypeScript strictly
- Avoid `any`
- Use functional components
- Keep components small
- Do not add dependencies without a concrete need
- Prefer semantic HTML
- Respect reduced-motion preferences
- Keep translations outside components
- Do not hard-code theme colors repeatedly
- Use named exports for reusable components
- Run lint and build before completing changes

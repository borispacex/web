# BORISPACEX Brand Assets

Todos los assets de esta carpeta pertenecen al mismo sistema visual y parten del mismo astronauta maestro.

## Uso

- `logo/`: lockups completos, horizontales, símbolo y monograma BX.
- `hero/`: ilustración del astronauta sin texto en WebP y PNG.
- `icons/`: iconos de producto con `viewBox="0 0 24 24"`, stroke `1.7` y esquinas redondeadas.
- `backgrounds/`: decoraciones sutiles para fondos; no deben competir con el contenido.

Las variantes `dark` están preparadas para fondos oscuros y las variantes `light` para fondos claros. No deben deformarse, rotarse ni recolorearse fuera de la paleta oficial.

Los favicons, app icons y piezas sociales se mantienen en `public/brand/` porque necesitan URLs públicas directas.
